# LovaCRM - Система управљања клијентима

Професионални CRM систем за управљање клијентима, резервацијама и пословним процесима.

## 🚀 Функције

- **Управљање клијентима** - Комплетна база података клијената
- **Систем резервација** - Организација и праћење резервација
- **Мапа локација** - Визуелни приказ локација и клијената
- **Маркетинг алатке** - Комуникација са клијентима
- **Админ панел** - Управљање корисницима и системом
- **Пробни период** - Аутоматски систем пробног приступа
- **Двофакторна аутентификација** - Безбедност за админе

## 🛠 Технологије

- **Backend**: Python FastAPI
- **Frontend**: HTML, CSS, JavaScript
- **База података**: SQLite
- **Стилизовање**: Tailwind CSS
- **Иконице**: Lucide Icons

## 📦 Инсталација

1. **Клонирајте репозиторијум**
```bash
git clone <repository-url>
cd crm-1.1
```

2. **Инсталирајте зависности**
```bash
pip install -r requirements.txt
```

3. **Покрените сервер**
```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## ⚙️ Конфигурација

### Email подешавања
Копирајте `env.example` у `email_config.env` и попуните:

```env
EMAIL_ENABLED=true
EMAIL_SMTP_SERVER=smtp.gmail.com
EMAIL_SMTP_PORT=587
EMAIL_USERNAME=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
```

### База података
Систем аутоматски креира SQLite базу података при првом покретању.

## 🔐 Безбедност

- **Хеширање лозинки**: SHA256
- **Сесије**: Безбедно управљање сесијама
- **2FA**: Двофакторна аутентификација за админе
- **Пробни период**: Аутоматско замораживање истеклих налога
